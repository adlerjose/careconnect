# Fontes licenciadas

A identidade visual usa **Neue Montreal** (Pangram Pangram Foundry), uma fonte comercial.
Os arquivos **não** estão incluídos no repositório por questões de licença.

Se o projeto possuir licença de uso web, adicione aqui:

| Arquivo                         | Peso |
| ------------------------------- | ---- |
| `NeueMontreal-Light.woff2`      | 300  |
| `NeueMontreal-Regular.woff2`    | 400  |
| `NeueMontreal-Medium.woff2`     | 500  |

A declaração `@font-face` em `src/styles/fonts.css` já aponta para esses arquivos.
Enquanto eles não existirem, a interface usa **Inter** (licença SIL OFL, auto-hospedada via
`@fontsource/inter`) como **fonte substituta** — ela não é a Neue Montreal.
